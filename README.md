## 🚀 Featured Work

### Nudgewright — Human-Approved Automation Engine (Rust)

An open-source Rust engine for reminder automation where a person approves exactly what is sent. Approval is tied to a content hash, sending happens exactly once (even across crashes), and every action goes to an append-only audit log. The AI only words drafts, and its token cost is logged.

**Built with:** Rust, PostgreSQL, Claude API · written agent rules, about 127 tests, and CI on every push.

→ [github.com/Enriquez-Johnmark/nudgewright](https://github.com/Enriquez-Johnmark/nudgewright)

### Kompleto — First Product on Nudgewright

Automates document and BIR-deadline follow-ups for Philippine bookkeepers, with human approval built in.

### Aegir — Fleet Operations & Safety

A multi-tenant maritime safety and fleet operations workspace covering vessels, inspections, work orders, and shift handovers, with an audit trail.

**Built with:** Next.js, TypeScript, Supabase, PostgreSQL, Vitest, Playwright.
